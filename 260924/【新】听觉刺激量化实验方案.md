# 听觉刺激量化实验方案（Pre Examination 参考文档）

> 用途：为「任务启动」项目中的听觉前测提供量化维度、实验设计和文献支持。
> 核心逻辑：**先人后工具**——Step 1 用多样化的真实音频让人产生主观+生理反应，筛出"有效/无效"两组；Step 2 才用心理声学工具去反推到底是哪个参数把两组区分开；Step 3（可选）基于 Step 2 的发现做受控验证实验。工具不预先介入音频的设计，只在筛选完成后介入分析。

---

## 一、量化听觉刺激的总体框架

**声学 / 心理声学层面的客观参数**（描述声音本身，Step 2 才会用工具去算）：频率（Hz）、节奏/拍速（BPM）、声压级（dB）、响度（loudness）、锐度（sharpness）、粗糙度（roughness）、波动强度（fluctuation strength）。这套体系来自 Zwicker & Fastl 的心理声学理论。

**认知 / 行为层面的因变量**（Step 1 直接测人）：反应时及其变异性(RT variability/SD)——持续注意测验里最敏感的指标之一，对 ADHD 尤其敏感；遗漏错误/虚报错误(omission/commission errors)——听觉遗漏错误是区分 ADHD 组和对照组最可靠的变量之一。

---

## 二、Step 1：多样化音频库 + 主观量表 + 生理指标初筛

**核心原则**：音频来源要"随意"、覆盖面要"宽"，不能是精确合成好的受控组合——那等于工具已经先把答案算了一遍。文献只用来确定候选池要覆盖哪些维度的两端，具体每段音频交给真实世界的多样素材。**唯一的例外是"响度"这个维度**——响度是纯振幅缩放，不改变音频的频率/节奏内容，所以必须用同一段音频调音量大小来控制，而不是去找不同的音频，这样才能保证只有响度单一变量在组间变化。

### 2.1 候选音频库的覆盖范围——理论依据

- Patterson, R. D. (1982). *Guidelines for auditory warning systems on civil aircraft*：警示音感知音高安全区间在150–1000Hz——候选池至少要覆盖明显偏低（几百Hz）和明显偏高（上千Hz）的音频
- Haas & Edworthy (1996)：频率、声压级、脉冲间隔都影响紧迫感——这篇研究本身也是固定基础音色、只调SPL来体现响度差异，本方案的响度控制方式与其一致
- Milliman (1982) / Brodsky (2002) 节奏分类：慢速<72 BPM，快速>94–140 BPM
- Bradley & Lang (2007), *IADS-2*：情绪声音的valence/arousal分布两端稀疏、中间密集——挑选时要刻意找"极端"的声音
- Gaver, W. W. (1986). *Auditory Icons*：区分Auditory Icons（自然环境声，带语义联想）和Earcons（抽象合成音）——Step 1两种都要有，因为还不知道"有效"的音频靠的是语义联想还是纯声学参数

### 2.2 候选音频清单——4个内容组 × 2个响度版本 + 人声对照组

先找齐**频率×节奏**的2×2组合（4段不同内容的真实音频），每段各自调出一个大声版本和一个小声版本，自然凑出8条音频；人声组单独处理，不参与响度控制逻辑（人声测的是语义/语气差异）。

| 内容组 | 频率  | 节奏  | 找什么样的音频（关键词/来源建议）                                    |
| --- | --- | --- | ---------------------------------------------------- |
| C1  | 低   | 慢   | 远处闷雷（Freesound搜"distant thunder rumble"）或慢速ambient音乐 |
| C2  | 低   | 快   | 快节奏重低音音乐循环（Tunebat先筛BPM>110且低音突出的片段）                 |
| C3  | 高   | 慢   | 风铃（Freesound搜"wind chimes"）或间隔长的单只鸟鸣                 |
| C4  | 高   | 快   | 密集鸟群啾鸣（Freesound搜"bird flock chirping"）或连续通知音        |

**每段用Audacity做两个响度版本**（"Effect > Amplify"调整增益）：

| 编号 | 内容 | 响度 |
|---|---|---|
| C1-loud | C1 | ~75dB |
| C1-quiet | C1 | ~55dB |
| C2-loud | C2 | ~75dB |
| C2-quiet | C2 | ~55dB |
| C3-loud | C3 | ~75dB |
| C3-quiet | C3 | ~55dB |
| C4-loud | C4 | ~75dB |
| C4-quiet | C4 | ~55dB |

**人声对照组**（独立于上述响度控制逻辑）：

| 编号 | 内容 |
|---|---|
| V1 | 自己录"该起床了"——平静语气 |
| V2 | 自己录同一句话——急促催促语气 |

**共10条音频**（8条内容×响度组合 + 2条人声），每段统一截取6-10秒最有代表性的片段。

### 2.3 现成的音频来源网站

**国际免费音效库**：
- **Freesound.org**——最大的CC协议音效库，注册后搜索关键词直接下载，注意区分CC0（可自由使用）和CC-BY（需标注来源）
- **Zapsplat**——免费注册后下载，有"notification"、"alarm"、"alert"分类
- **Mixkit**——无需注册即可下载，免费商用音效库
- **BBC Sound Effects Archive**——BBC官方免费音效库，自然声、环境声质量高，个人非商业用途免费

**中文音效库**：
- **耳聆网（ear0.com）**——专注自然环境声和生活声音的中文音效网站
- **爱给网（aigei.com）**——综合性素材网站，部分资源需注意版权/会员限制

**标准化情绪声音库（可选，效度校准用）**：
- **IADS-2**（Bradley & Lang, 2007）——已标注valence/arousal分数的声音库，需向University of Florida NIMH情绪与注意力研究中心申请获取

**BPM查询工具**（网页版，不需要下载）：
- **Tunebat.com**——直接打开网址搜歌名查BPM，或上传音频文件自动分析（"Song Key & BPM Finder"功能），手机/电脑浏览器都能用
- **SongBPM.com**——同样是网页工具，搜歌名即可
- 如果需要离线批量分析，可在App Store搜**"BPM Finder"**（支持批量分析音频文件）

**人声素材**：不需要外部网站，自己用手机录音App录制。

**版权提醒**：下载后请核对各平台授权协议，学术研究/课堂展示风险较低，但如作品集需公开展示或用于竞赛投稿，优先选CC0或注明来源的素材。

### 2.4 音频预处理规范

1. **格式统一**：全部转成WAV，44.1kHz采样率（Audacity导出即可）
2. **时长裁切**：每段截取6-10秒最有代表性的片段
3. **响度控制**：用Audacity的"Amplify"功能把每个内容组分别调到~55dB和~75dB两个版本（这是本方案唯一需要主动调整参数的一步，用于严格控制响度这一单一变量）

### 2.5 生理指标测量方案（ECG+ 30秒方案）

统一用Apple Watch S10的ECG功能 + **ECG+** App，每段音频测一次，HR和HRV一次拿到：

- 每次实验前先测一次**静息baseline**（30秒，不播放任何音频），作为该被试的个人基线
- 之后每段候选音频播放时同步触发ECG：一手按住表冠开始记录，另一只手同时按下音频播放（手动同步，误差1-2秒可接受，ECG无法用快捷指令自动触发）
- **音频时长处理按类型区分**：
  - 音乐/自然环境声类：可循环播放填满整个30秒，直接用ECG+报告给出的整体RMSSD/HR数值
  - 警示音/通知音/人声这类短促类型：保持原始6-10秒时长，不循环拉长（避免扭曲原本听感），30秒记录里前段对应"刺激期"、后段对应"恢复期"，重点看ECG+报告的R-R时间序列图在刺激前后的波动趋势变化作为定性参考
- **每次记录的数据**：HRV(rMSSD)、HR均值、RR均值——ECG+报告直接给出，无需额外计算
- **组间比较用ΔHRV/ΔHR**（该次数值-个人baseline），抵消个体静息心率差异

**素材登记表模板**：

| 被试编号 | 音频编号 | 类型 | HRV(rMSSD) | HR均值 | RR均值 |
|---|---|---|---|---|---|
| P01 | baseline | - | | | |
| P01 | C1-loud | 自然声-低频慢-大声 | | | |
| P01 | C1-quiet | 自然声-低频慢-小声 | | | |
| P01 | V1 | 人声-平静 | | | |

### 2.6 问卷量表具体题目

每段音频播放结束后，立即用7点Likert量表（1=完全不同意，7=完全同意）打分：

- **唤醒度（Arousal）**："这段声音让我感觉很清醒/被激活"
- **紧迫感（Urgency）**（核心维度，对应task initiation）："这段声音让我觉得需要马上做点什么"
- **烦躁度（Annoyance）**："这段声音让我觉得刺耳/不舒服"
- **行为意图校验题**（二选一）："如果这是一个任务提醒音，你会立刻放下手头的事去处理吗？"[会/不会]

三维度划分参考Hellier & Edworthy系列研究里把"perceived urgency"作为独立于纯情绪valence/arousal的第三维度处理的方式。

### 2.7 被试量与流程

- **样本量**：20-25人
- **设计类型**：被试内设计，每人听全部10段音频
- **顺序控制**：拉丁方或完全随机化排列播放顺序
- **单次实验时长**：每段音频约需"30秒ECG+10秒左右播放+20秒填量表"，10段下来单人约20-25分钟

### 2.8 筛选判断标准（四象限）

| | 生理反应强 | 生理反应弱 |
|---|---|---|
| **主观评分高** | 强有效候选 | 需二次确认（可能是社会期望效应） |
| **主观评分低** | 潜在阈下有效候选（最有设计价值） | 无效，排除 |

Step 1结束后得到"有效音频组"和"无效音频组"，此时尚不知道是什么参数导致分组，这正是Step 2要解决的问题。

## 三、Step 2：用工具反推——到底是什么参数把两组分开了

**工具第一次出场，只分析Step 1真实筛出来的音频，不分析任何人工合成的音频。**

### 3.1 开源工具

**基础声学参数（`librosa`）**：节奏/BPM `beat.beat_track()`；基频 `pyin()`；频谱质心 `spectral_centroid()`；RMS `feature.rms()`

**心理声学参数（`MOSQITO`）**：
- 响度（ISO 532-1）：`mosqito.sq_metrics.loudness_zwst`
- 锐度（DIN 45692）：`mosqito.sq_metrics.sharpness_din_st`
- 粗糙度、波动强度：库内均有对应函数
- 安装：`pip install mosqito --break-system-packages`

### 3.2 分析流程

1. 把"有效组"和"无效组"音频逐条跑一遍librosa + MOSQITO，得到每条音频的完整参数表
2. 做组间对比（t检验，或画"频率×节奏"、"响度×粗糙度"散点图看是否分离）
3. 找出哪个/哪几个参数在两组间差异最显著——这是从数据里长出来的结论，不是提前预设的

## 四、Step 3（可选）：基于Step 2的发现做受控验证实验

只有在Step 2已经告诉你"哪个参数重要"之后，才值得做这一步——用合成音频做纯净的因果验证，排除掉Step 1真实音频里混杂的语义、音色等干扰变量。

假设Step 2发现"基频"和"节奏"是关键区分变量，做一个2×2的合成音频因子实验：

| 条件 | 基频（按Step 2实测高低两组均值设定） | 节奏（同上） |
|---|---|---|
| B1 | 低 | 慢 |
| B2 | 低 | 快 |
| B3 | 高 | 慢 |
| B4 | 高 | 快 |

制作方式：用Audacity或Python合成正弦波/方波脉冲，固定其他变量，只操纵这两个已被Step 2证实重要的参数。

这一步才用得上Patterson (1982)的脉冲设计规范（单脉冲300-500ms，循环组成6-10秒片段）、Gaver (1986)关于Earcon应排除语义干扰的建议，以及Hellier et al. (2002)关于语义会独立影响紧迫感判断的发现。

## 五、生理指标选择的背景说明（写作参考）

- 曾考虑皮肤电反应（EDA/GSR），因需要额外硬件（Grove-GSR传感器+Arduino开发）被判断为工作量过大而放弃
- 曾考虑Apple Watch后台算法给出的HRV（依赖光学心率传感器），但该数据是苹果闭源黑箱算法零星触发的结果，第三方App无法编程获取逐拍原始数据，采样密度不足以对应每段音频，因此放弃；且锻炼模式只能让心率变为连续采样，不能让HRV变为连续采样，两者机制不同
- 最终采用**ECG功能**：因为ECG走的是电极直接测心脏电信号的路径（512Hz采样），原始波形数据可通过HealthKit的`HKElectrocardiogram`接口读取，第三方App（如ECG+）可据此自动检测R波并计算出真正意义上的RMSSD——这条路径技术上真实可行，但代价是每次测量需手动触发+30秒静止，无法后台自动连续监测
- Brouwer et al. (2013)：心率更多反映愉悦度(valence)，心率变异性(HRV)更贴近唤醒度(arousal)——这是加入HRV而不只依赖心率的理论依据
- 曾考虑加速度计/陀螺仪捕捉手腕启动动作的精确时间，因需额外watchOS开发被判断为工作量过大而放弃；血氧、心肺适能(VO2 Max)、恢复心率等指标因与研究问题关联弱或颗粒度不够对应单段音频而未采用
